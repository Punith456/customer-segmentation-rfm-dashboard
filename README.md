# Customer Segmentation – RFM Analytics Dashboard

An interactive customer segmentation dashboard based on RFM
(Recency, Frequency, Monetary) analysis.

## Project Overview

This project analyzes customer purchasing behavior and divides
customers into meaningful segments based on their RFM scores.

The dashboard identifies segments such as Champions, Loyal Customers,
Potential Loyalists, New Customers, At Risk, Hibernating, and Lost.

## Features

- RFM-based customer segmentation
- Revenue analysis by customer segment
- Customer distribution visualization
- Recency × Frequency heatmap
- Retention analysis
- Business insights and recommendations
- Interactive dashboard

## Technologies Used

- Python
- Pandas
- Matplotlib
- HTML
- CSS
- JavaScript
- Chart.js
